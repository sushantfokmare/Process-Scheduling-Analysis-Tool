# CPU Scheduling Simulator 🖥️⏱️

## 📜 Project Overview
This Java program simulates multiple CPU scheduling algorithms commonly taught in Operating Systems courses.  
It supports:
- First-Come, First-Served (FCFS)  
- Shortest-Job-First (SJF) — Non-preemptive & Preemptive (SRTF)  
- Priority Scheduling — Non-preemptive & Preemptive  
- Round-Robin (RR)

The program reads process details (burst time, arrival time, priority) from the user, runs the chosen algorithm, prints a simple Gantt chart, and shows average waiting time where applicable.

---

## ✨ Features
- ✔️ FCFS (First-Come, First-Served)  
- ✔️ SJF Non-preemptive  
- ✔️ SJF Preemptive (Shortest Remaining Time First)  
- ✔️ Priority Scheduling (non-preemptive & preemptive)  
- ✔️ Round-Robin with user-specified time quantum  
- ✔️ Gantt chart style output in console  
- ✔️ Average waiting time calculation for non-preemptive algorithms and RR

---

## 🛠️ Technologies
- 🔷 Java (JDK 8+)
- 📦 Uses `java.util` collections and `Scanner` for input
